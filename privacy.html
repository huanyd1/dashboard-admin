Privacy Policy

This application uses TikTok API to allow users to connect their account and manage video content.

Data We Collect

  • TikTok user ID (open_id)
  • Basic profile information
  • Access token (temporarily stored for API requests)

How We Use Data

  • To authenticate user via TikTok OAuth
  • To upload and manage videos on behalf of the user

Data Sharing

We do not sell or share user data with third parties.

Security

All tokens are stored securely and used only for API requests.
